VSCode + PlatformIO 开发单片机指南

适用芯片： STC15F2K60S2（蓝桥杯 CT107D 开发板）
替代方案： 完全替代 Keil C51 + STC-ISP 的开发流程
前置知识： 了解基本的 C 语言和单片机概念

一、为什么选择 VSCode + PlatformIO

对比项 Keil C51 VSCode + PlatformIO
价格 需要破解激活 完全免费开源
编辑器 功能简陋，代码提示弱 现代编辑器，智能补全、多光标
跨平台 仅 Windows Windows / macOS / Linux
编译器 Keil C51 专有编译器 SDCC（Small Device C Compiler）
代码管理 无集成 内置 Git 支持
主题 丑 好看
插件生态 几乎没有 海量插件
  1. PlatformIO 使用 SDCC 编译器，语法与 Keil C51 有少量差异（详见八、Keil 与 PlatformIO 语法差异）
  2. 烧录仍需要 STC-ISP（或命令行工具 stcgal），PlatformIO 对 STC 单片机的烧录支持有限
  3. 如果蓝桥杯比赛要求必须用 Keil，建议平时用 PlatformIO 开发调试，赛前熟悉 Keil 操作

二、软件安装

2.1 安装 VSCode

  1. 下载安装包

    • 访问官网：https://code.visualstudio.com
    • 选择对应系统版本下载（Windows / macOS / Linux）

  2. 安装步骤

    • 双击运行安装程序
    • 建议勾选以下选项：
      • 添加到 PATH（通过 Shell 命令打开）
      • 在此处打开 Code（右键菜单快捷方式）
    • 安装路径避免中文和空格

  3. 推荐插件（安装完 VSCode 后先装这些）

插件名 用途
PlatformIO IDE 单片机开发核心插件
C/C++ Microsoft 官方 C/C++ 支持
Chinese Language Pack 中文界面（可选）

安装 PlatformIO IDE 插件时会自动下载 Python 依赖和工具链，首次安装可能需要 5-10 分钟，请耐心等待。

2.2 安装 PlatformIO IDE 插件

  1. 打开 VSCode
  2. 点击左侧活动栏的 扩展图标（或按 Ctrl + Shift + X）
  3. 搜索 PlatformIO IDE
  4. 点击 Install 安装
  5. 安装完成后，左侧活动栏出现 外星人头像图标（PlatformIO Home）
  6. 等待底部状态栏显示 ✓ Ready
  • 下载慢/超时：PlatformIO 默认从 GitHub 下载工具链，如果网络不好，可设置代理：
  • 打开 VSCode 设置 → 搜索 platformio → 设置 HTTP Proxy
  • Python 报错：PlatformIO 依赖 Python 3.6+，确保系统已安装 Python
  • Windows 权限问题：以管理员身份运行 VSCode

2.3 验证安装

  1. 点击左侧 PlatformIO 图标
  2. 点击 PIO Home → Open
  3. 能正常打开欢迎页面即安装成功

五、程序烧录

5.1 方式一：STC-ISP 烧录（推荐新手）

PlatformIO 对 STC 单片机的直接烧录支持有限，推荐使用 STC-ISP 软件烧录。

步骤：

  1. 找到 HEX 文件

    • 编译成功后，HEX 文件位于 .pio/build/stc15f2k60s2/firmware.hex
    • 可以在 PlatformIO 侧边栏 → PROJECT TASKS → Build 的输出中看到完整路径

  2. 打开 STC-ISP

    • 运行 stc-isp-xxx.exe
    • 单片机型号选择：IAP15F2K61S2
    • 时钟频率：12MHz

  3. 连接单片机

    • 用 USB 线连接开发板和电脑
    • 在 STC-ISP 中查看"串口号"，确认连接成功
    • 点击"打开程序文件"，选择上面找到的 .hex 文件

  4. 下载程序

    • 先点击"下载/编程"
    • 然后给单片机重新上电（拔插 USB 或按开发板复位键）
    • 等待下载完成

STC 单片机使用冷启动烧录——必须先点击"下载"，再给芯片上电。这是 STC 的 ISP 下载协议决定的。

九、常见问题与解决方案

Q1：编译报错 fatal error: stc15f2k60s2.h: No such file

原因： SDCC 的头文件路径不对或未安装对应的设备包。

解决：

  1. 确认 platformio.ini 中 board = STC15F2K60S2 配置正确
  2. 手动下载头文件放入 include/ 目录
  3. 或者在 PlatformIO Home → Platforms 中安装 intel_mcs51 平台

Q2：编译报错关于 sbit、interrupt 等关键字

原因： SDCC 语法与 Keil 不同。

解决： 按照八、Keil 与 PlatformIO 语法差异修改代码。

Q3：烧录失败，提示串口错误

原因： 串口号配置错误或驱动未安装。

解决：

  1. Windows：在设备管理器 → 端口(COM 和 LPT) 中查看实际串口号
  2. Linux/macOS：运行 ls /dev/tty* 查看串口设备
  3. 确认已安装 CH340/CP2102 等 USB 转串口驱动
  4. 修改 platformio.ini 中的 upload_port 为正确的串口号

Q4：PlatformIO 找不到 STC15 开发板

解决： 手动创建项目，在 platformio.ini 中指定通用 8051 平台配置。

Q5：中文注释乱码

解决：

  1. 确保 .c 文件使用 UTF-8 编码保存
  2. VSCode 右下角状态栏可切换编码格式
  3. SDCC 默认支持 UTF-8，比 Keil 的 ANSI 编码更好

Q6：代码补全不生效

解决：

  1. 安装 C/C++ 扩展（Microsoft 官方）
  2. 运行一次编译（Ctrl + Alt + B），让 PlatformIO 生成 c_cpp_properties.json
  3. 如果仍不生效，按 Ctrl + Shift + P → C/C++: Edit Configurations 手动添加 include 路径

十、开发工作流总结

  1. 在 VSCode + PlatformIO 中编写和编译代码（享受智能补全和现代编辑器）
  2. 使用 STC-ISP 烧录（稳定可靠）
  3. 利用 PlatformIO 的串口监视器调试输出
  4. 使用 VSCode 内置 Git 管理代码版本
