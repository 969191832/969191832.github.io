一、实验目的

  • 掌握定时器/计数器的工作原理；
  • 掌握定时器实现定时功能的软硬件设计。

二、实验设备

  • windows操作系统
  • keil5
  • STC-ISP
  • 蓝桥杯竞赛专用单片机

三、实验内容

S4按键闭合，P0口LED灯以1S间隔闪烁，1S时间间隔由定时器实现。S4松开LED灯熄灭。

四、实验原理

定时器概述

STC15系列单片机内置多个定时器/计数器，可用于定时、计数、PWM输出等功能。

定时器 工作模式 中断号 主要用途
Timer0 16位定时/计数 1 定时中断、PWM
Timer1 16位定时/计数 3 定时中断、串口波特率
Timer2 16位定时/计数 5 定时中断、波特率发生器

定时器工作原理

定时器本质上是一个计数器，每个机器周期计数一次。当计数值达到最大值（65535）溢出时，产生中断请求。

定时时间计算公式：

机器周期：

  • 12T模式：机器周期 = 12 / 晶振频率
  • 1T模式：机器周期 = 1 / 晶振频率（STC15系列支持）

12MHz晶振下的机器周期：

模式 机器周期 1ms定时初值
12T 1μs 65536 - 1000 = 64536 (0xFC18)
1T 1/12μs 65536 - 12000 = 53536 (0xD120)

定时器相关寄存器

TMOD寄存器（定时器模式寄存器）：

位 名称 功能
7 GATE1 定时器1门控位
6 C/T1 定时器1计数/定时选择（0=定时，1=计数）
5-4 M1_1, M0_1 定时器1工作模式选择
3 GATE0 定时器0门控位
2 C/T0 定时器0计数/定时选择
1-0 M1_0, M0_0 定时器0工作模式选择

定时器工作模式：

M1 M0 模式 说明
0 0 模式0 16位自动重装定时器（STC15特有）
0 1 模式1 16位定时器（需手动重装）
1 0 模式2 8位自动重装定时器
1 1 模式3 定时器0分为两个8位定时器

AUXR寄存器（辅助寄存器）：

位 名称 功能
7 T0x12 定时器0速度：1=1T模式，0=12T模式
6 T1x12 定时器1速度：1=1T模式，0=12T模式

TCON寄存器（定时器控制寄存器）：

位 名称 功能
7 TF1 定时器1溢出标志（硬件置1，软件清0或中断响应自动清0）
6 TR1 定时器1运行控制（1=启动，0=停止）
5 TF0 定时器0溢出标志
4 TR0 定时器0运行控制
3 IE1 外部中断1标志
2 IT1 外部中断1触发方式
1 IE0 外部中断0标志
0 IT0 外部中断0触发方式

IE寄存器（中断允许寄存器）：

位 名称 功能
7 EA 总中断允许
3 ET1 定时器1中断允许
1 ET0 定时器0中断允许

定时器初始化步骤

以定时器0为例，定时1ms（12MHz，1T模式）：

  1. 设置工作模式：TMOD &= 0xF0; （定时器0设为16位定时器模式）
  2. 设置速度模式：AUXR |= 0x80; （1T模式）
  3. 装载初值：TL0 = 0x20; TH0 = 0xD1;
  4. 开启中断：ET0 = 1; EA = 1;
  5. 启动定时器：TR0 = 1;

定时器初值计算

方法一：手动计算

例如：1ms定时，12MHz晶振，1T模式

方法二：使用STC-ISP工具

  1. 打开STC-ISP软件
  2. 选择"定时器计算器"功能
  3. 设置晶振频率、定时时间
  4. 自动生成初始化代码
