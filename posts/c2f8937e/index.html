实验5 路由器基本配置与静态路由

Created2026-04-28|Updated2026-04-28|计算机网络实验
|Post Views:

一、实验目的

  1. 掌握路由器物理接口 IP 地址的配置方法。
  2. 理解路由器与交换机在接口属性上的区别（三层接口 vs 二层接口）。
  3. 掌握查看路由器路由表（Routing Table）的方法。
  4. 通过配置静态路由（Static Route），实现跨网段的端到端通信。
  5. 理解"下一跳"和"出接口"在路由配置中的含义。

二、实验环境

  1. 硬件：个人电脑（建议内存 8G 以上）。
  2. 软件：eNSP 仿真平台。
  3. 设备选型：Router (如 AR2220) 两台，PC 两台。

三、实验内容及步骤、结果

1. 实验拓扑回顾 (eNSP)

  • PC1 (192.168.1.1/24) <–> R1 [GE 0/0/0]

  • R1 [GE 0/0/1] (10.0.0.1/30) <–> R2 [GE 0/0/1] (10.0.0.2/30)

  • R2 [GE 0/0/0] <–> PC2 (192.168.2.1/24)

5. 关键检查命令（结果验证）

配置完成后，请引导学生使用以下命令排查问题：

  1. 检查接口是否双 UP：
    display ip interface brief

    • 要求：GE 0/0/0 和 GE 0/0/1 的 Physical 和 Protocol 必须都是 up。

  2. 检查路由表是否包含静态路由：
    display ip routing-table

    • 要求：在 R1 的路由表中必须能看到 192.168.2.0/24 的条目。

  3. 连通性测试：

    • 在 PC1 上：ping 192.168.1.254（测自家网关）

    • 在 PC1 上：ping 10.0.0.2（测对端路由器接口）

    • 在 PC1 上：ping 192.168.2.1（跨网段全通）

四、思考题

  1. 接口对比：在实验三中，我们无法直接在交换机的物理接口上配置 IP 地址，而路由器可以。请问这是为什么？（提示：从二层接口与三层接口的区别回答）。

  2. 回程路由：在配置静态路由时，如果只在 R1 上配置了去往 PC2 的路由，而没有在 R2 上配置回 PC1 的路由，PC1 执行 Ping 操作时会发生什么？为什么？

  3. 路由优先级：在 display ip routing-table 中，Proto 为 Static 的路由，其默认的 Preference（优先级）是多少？如果同时存在一条去往相同网段的"直连路由"，路由器会优先选哪一条？

  4. 下一跳 vs 出接口：在配置静态路由 ip route-static 时，既可以指定"下一跳 IP 地址"，也可以指定"本地出接口"。在广播型网络（如以太网）中，为什么通常建议指定"下一跳 IP"？

  5. 网关的作用：如果 PC1 没有配置默认网关（Default Gateway），它还能 Ping 通同一网段的 R1 GE0/0/0 接口吗？还能 Ping 通 PC2 吗？
