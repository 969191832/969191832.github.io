实验1 虚拟机安装

Created2026-04-28|Updated2026-04-28|计算机网络实验
|Post Views:

一、实验目的

  1. 掌握 VMware Workstation 虚拟化软件的安装流程。
  2. 深入理解虚拟机三种网络模式（桥接模式、NAT 模式、仅主机模式）的工作原理。
  3. 学会根据不同的网络需求配置虚拟网络环境。
  4. 掌握基础的网络诊断命令（如 ping, ipconfig, ifconfig 等）验证网络连通性。

二、实验环境

  1. 硬件：支持硬件虚拟化技术（VT-x 或 AMD-V）的个人电脑。
  2. 操作系统：Windows 10/11 主机。
  3. 软件：
    • VMware Workstation Pro 17 或更高版本。
    • 已安装好的客户机操作系统（建议使用 Ubuntu 或 Windows 10 虚拟机镜像）。

三、实验内容及步骤

1. VMware 的安装与准备

  • 步骤：下载并运行 VMware Workstation 安装包，按照提示完成安装。
  • 注意：安装过程中勾选"增强型键盘驱动程序"以获得更好体验。安装完成后，需进入 BIOS 确认 CPU 虚拟化功能已开启。

2. 桥接模式（Bridged Mode）配置与验证

原理：虚拟机如同局域网中一台独立的主机，直接连接到物理网络。它与物理机处于同一网段，可以直接访问外部网络，外部设备也可以直接访问该虚拟机。

  • 配置步骤：
    1. 在 VMware 菜单栏选择【编辑】->【虚拟网络编辑器】。
    2. 点击【更改设置】（需要管理员权限）。
    3. 选择 VMnet0，将"桥接模式"设置为"自动"或指定的物理网卡（如：Intel Wi-Fi 6）。
    4. 选中目标虚拟机，点击【编辑虚拟机设置】，将"网络适配器"选为"桥接模式"。
  • 验证步骤：
    1. 启动虚拟机，进入系统命令行（CMD 或 Terminal）。
    2. 使用 ipconfig (Windows) 或 ip addr (Linux) 查看 IP 地址。
    3. 预期结果：虚拟机的 IP 地址与宿主机的 IP 地址在同一网段（例如宿主机是 192.168.1.5，虚拟机是 192.168.1.10）。
    4. 测试连通性：ping www.baidu.com 以及 ping [宿主机IP]。

3. NAT 模式（Network Address Translation）配置与验证

原理：虚拟机通过宿主机的网络访问外部网络。宿主机充当了"路由器"的角色，虚拟机处于一个私有的内部网络（VMnet8），外部网络无法直接访问虚拟机。

  • 配置步骤：
    1. 在【虚拟网络编辑器】中选择 VMnet8。
    2. 确保勾选"将主机虚拟适配器连接到此网络"及"使用本地 DHCP 服务"。
    3. 查看【NAT 设置】，记录"网关 IP"（通常为 x.x.x.2）。
    4. 将虚拟机的"网络适配器"设置为"NAT 模式"。
  • 验证步骤：
    1. 查看虚拟机 IP 地址。
    2. 预期结果：虚拟机的 IP 地址与宿主机在不同网段（位于 VMnet8 指定的网段中）。
    3. 测试连通性：
      • 虚拟机 ping 外部网站（应通）。
      • 虚拟机 ping 宿主机物理 IP（应通）。
      • 宿主机 ping 虚拟机 IP（应通，因为有 VMnet8 虚拟网卡）。

4. 仅主机模式（Host-Only Mode）配置与验证

原理：虚拟机仅能与宿主机及其他处于同一仅主机模式下的虚拟机通信。默认情况下，虚拟机无法访问互联网。这是一个完全隔离的网络环境。

  • 配置步骤：
    1. 在【虚拟网络编辑器】中选择 VMnet1。
    2. 将虚拟机的"网络适配器"设置为"仅主机模式"。
  • 验证步骤：
    1. 查看虚拟机 IP 地址。
    2. 预期结果：虚拟机获取到 VMnet1 网段的 IP。
    3. 测试连通性：
      • 虚拟机 ping 宿主机 VMnet1 网卡 IP（应通）。
      • 虚拟机 ping 外部网站（应不通）。

四、思考题

  1. 场景分析：如果你在一个咖啡馆使用公共 Wi-Fi，且该 Wi-Fi 限制每个账号只能一台设备上网，你应该选择哪种网络模式来让虚拟机也能上网？为什么？

    • 提示：考虑桥接模式是否会占用多个 IP。

  2. 安全性讨论：在进行病毒样本分析或由于实验需要搭建一个完全封闭的内网环境时，哪种模式最安全？为什么？

  3. 连接失败排查：在桥接模式下，如果虚拟机无法获取 IP 地址，可能的原因有哪些？（至少列举两点）。

  4. IP 构成：观察 NAT 模式下的网关 IP、DHCP 地址池范围。为什么通常网关 IP 不设为 .1 而是 .2？（提示：观察宿主机的虚拟网卡 VMnet8 占用了哪个地址）。
