一、Keil C51 安装与激活

1.1 安装 Keil C51

  1. 安装程序准备

    • 运行 c51v956.exe 安装程序
    • 建议直接安装到 C 盘默认目录，避免路径中包含中文或特殊字符

  2. 安装步骤

    • 双击运行安装程序
    • 按照默认设置完成安装
    • 安装完成后，重启计算机

1.2 Keil C51 激活

1.2.1 获取计算机 ID (CID)

  1. 以管理员权限打开 Keil C51 软件
  2. 点击 File → License Management
  3. 在弹出的窗口中复制 CID（Computer ID）码

1.2.2 激活步骤

  1. 运行激活工具

    • 双击运行 keygen_new2032.exe
    • 安全提示：运行前建议暂时关闭 Windows 安全中心，并系统静音

  2. 生成许可证

    • 在激活工具中粘贴复制的 CID
    • 点击 Generate 生成许可证密钥
    • 将生成的 License 密钥复制到 Keil 的 “LIC” 输入框
    • 点击 Add LIC 完成激活

  3. 验证激活

    • 激活成功后，界面会显示激活成功信息
    • 关闭激活工具

  4. 安全设置恢复

    • 恢复 Windows 安全中心设置
    • 现在可以正常使用 Keil C51 软件

1.3 编码设置优化

  1. 问题：Keil 默认使用 ANSI 编码，可能导致中文字符乱码
  2. 解决方案：将编码格式改为 UTF-8
  3. 设置路径：在 Keil 中选择相关设置项，将编码格式修改为 UTF-8 格式

二、STC-ISP 配置工具设置

2.1 STC-ISP 软件说明

  1. 软件版本：使用现有的 stc-isp-xxx.exe 版本，无需频繁更新
  2. 功能用途：单片机程序下载、串口调试、延时计算器等

2.2 STC 单片机型号配置

  1. 添加头文件到 Keil
    • 将 STC 单片机头文件复制到 Keil 安装目录
    • 确保 Keil 能识别 STC15F2K60S2 等型号
  1. 连接验证
    • 单片机连接到电脑后
    • 在 STC-ISP 中查看"串口号"
    • 如果显示"serial"等字样，表示单片机连接成功
  1. 单片机参数设置
    • 型号选择：IAP15F2K61S2
    • 时钟频率：12MHz

2.4 功能使用

  1. 软件延时计算器
    • 输入所需延时参数
    • 自动生成延时代码
  1. 硬件仿真功能

三、Keil 项目搭建

3.1 创建项目文件夹

  1. 在合适位置新建文件夹，如 01_exp
  2. 用于存放项目的所有相关文件

3.2 创建新项目

  1. 打开 Keil C51 软件
  2. 点击 Project → New Project

3.3 选择单片机型号

  1. 在设备选择对话框中选择：
    • 数据库：STC MCU Database
    • 型号：STC15F2K60S2
  1. 这边可以选择"否"

3.4 项目文件管理

  1. 展开项目结构
    • 点击 Target 1 右侧的 “+” 号
    • 展开所有项目项
  1. 添加文件
    • 添加新文件：右键菜单选择添加新文件
    • 添加现有文件：将已有源文件添加到项目中

3.6 编译设置

  1. 生成 HEX 文件
    • 确保勾选 Create HEX File 选项
    • 这样编译后会生成用于单片机烧录的 hex 文件
  1. 项目编译

四、注意事项

4.1 安装注意事项

  • 建议使用管理员权限进行安装和激活
  • 安装路径避免使用中文和特殊字符
  • 安装完成后重启计算机

4.2 激活注意事项

  • 激活工具运行时建议暂时关闭杀毒软件
  • 完成激活后及时恢复安全设置
  • 妥善保存激活工具和许可证文件
