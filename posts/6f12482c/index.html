实验3 碰撞域与广播域的验证

Created2026-04-28|Updated2026-04-28|计算机网络实验
|Post Views:

一、实验目的

  1. 理解集线器、交换机、路由器在二层（数据链路层）和三层（网络层）的工作差异。
  2. 通过抓包观察，验证**碰撞域（Collision Domain）的范围。
  3. 通过 ARP 报文流向，验证**广播域（Broadcast Domain）的隔离特性。
  4. 掌握 eNSP 抓包工具的使用方法及 ICMP/ARP 协议分析。

二、实验环境

  1. 硬件：win10操作系统
  2. 软件：eNSP、Wireshark、VirtualBox

三、实验内容及步骤

1. 碰撞域验证（集线器 vs 交换机）

(1) 拓扑搭建

  • 场景 A（集线器）：拖入一个 Hub，连接三台 PC（PC1, PC2, PC3）。
  • 场景 B（交换机）：拖入一台 S5700，连接三台 PC（PC4, PC5, PC6）。

(2) IP 配置

设备 IP 地址 子网掩码 备注
PC1/PC2/PC3 192.168.1.1~3 255.255.255.0 连接至 Hub
PC4/PC5/PC6 192.168.1.4~6 255.255.255.0 连接至 Switch

(3) 验证过程与抓包

  • 集线器测试：
    1. 在 PC2 与 Hub 的连线上右键点击"开始抓包"。
    2. 由 PC1 ping 192.168.1.3 (PC3)。
    3. 观察 Wireshark：发现 PC2 虽然不是目的地，但其链路上依然收到了 PC1 发往 PC3 的所有 ICMP 报文。
    4. 结论：集线器所有接口属于同一个碰撞域，物理层广播数据。
  • 交换机测试：
    1. 在 PC5 与 Switch 的连线上右键点击"开始抓包"。
    2. 由 PC4 ping 192.168.1.6 (PC6)。
    3. 观察 Wireshark：PC5 的链路上没有任何 ICMP 报文经过。
    4. 结论：交换机的每个接口都是一个独立的碰撞域。

2. 广播域验证（交换机 vs 路由器）

(1) 拓扑搭建

  • 左侧网络：PC7、PC8 连接至交换机 SW1。
  • 中间连接：SW1 连接至路由器 R1 的 G0/0/0 接口。
  • 右侧网络：R1 的 G0/0/1 接口连接至另一台 PC9。

(2) 设备配置

  • PC 配置：
设备 IP 地址 子网掩码 网关
PC7 192.168.10.1 255.255.255.0 192.168.10.254
PC8 192.168.10.2 255.255.255.0 192.168.10.254
PC9 192.168.20.1 255.255.255.0 192.168.20.254
  • 路由器 R1 配置：

(3) 验证过程与抓包

  1. 清空 ARP 缓存：在所有 PC 的命令行输入 arp -d。
  2. 开启抓包：
    • 同时开启 PC8 链路（交换机内侧）和 PC9 链路（路由器外侧）的抓包。
  3. 触发广播：在 PC7 命令行输入 ping 192.168.10.2。
    • 观察 PC8 链路：能抓到 ARP Request 广播包（Destination: Broadcast）。
    • 观察 PC9 链路：抓不到来自 192.168.10.0 网段的 ARP 广播包。
  4. 再次测试：由 PC7 ping 192.168.20.254 (跨网段)。
    • 观察：PC7 会发送 ARP 请求网关（10.254）的 MAC 地址，该广播包依然停留在 SW1 连接的所有设备中，不会穿过路由器到达 PC9。

四、结果记录表

交换机环境 PC4 -> PC6 PC5 否 是
路由器环境 PC7 -> R1 PC9 否 否

五、思考题

  1. 碰撞域与广播域的区别：

    • 如果把网络比作走廊，碰撞域意味着多个人同时说话会产生噪音（冲突），广播域意味着一个人喊话所有人都能听到。
    • 集线器既不隔离碰撞域，也不隔离广播域。
    • 交换机隔离了__________，但不隔离__________。
    • 路由器既隔离了__________，也隔离了__________。

  2. 交换机的行为：
    在实验 2 中，当 PC7 第一次 ping PC8 时，交换机会向所有接口转发 ARP 请求报文，这种操作称为什么？当交换机学习到 MAC 地址后，后续的 ICMP 包还会发送给 PC8 以外的接口吗？

  3. 路由器为何隔离广播：
    如果路由器不隔离广播域，当全球互联网（Internet）几十亿台设备中有一台发出 ARP 广播时，你的电脑会受到什么影响？

  4. VLAN 的作用（预习题）：
    在实际生产中，如果一个公司有 500 台电脑都连在互相级联的交换机上，广播包会非常多（广播风暴）。在不增加路由器的情况下，可以使用什么技术来划分广播域？

  5. Wireshark 过滤技巧：
    如果在抓包时只想看 ARP 报文，应该在过滤器栏输入什么关键字？如果只想看 PC1(192.168.1.1) 相关的包，应该输入什么？
