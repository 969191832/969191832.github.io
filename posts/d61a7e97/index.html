实验6 动态路由配置（RIP、OSPF）

Created2026-04-28|Updated2026-04-28|计算机网络实验
|Post Views:

一、实验目的

  1. 理解路由的基本概念，区分静态路由与动态路由的区别。
  2. 掌握静态路由的配置方法及路由表的查看方式。
  3. 掌握 RIP（Routing Information Protocol）协议的配置流程，理解其工作原理。
  4. 掌握 OSPF（Open Shortest Path First）协议的配置流程，理解区域划分的概念。
  5. 能够对比三种路由方式的异同，并能通过 ping 命令验证网络连通性。

二、实验环境

  1. 硬件：个人电脑（建议内存 8G 以上，以流畅运行 eNSP）。
  2. 软件：
    • eNSP V100R003 或更高版本。
    • Wireshark（用于后续协议分析）。
    • VirtualBox（eNSP 运行底座）。

三、实验内容及步骤、结果

1. 拓扑搭建

  • 操作：
    1. 打开 eNSP，新建拓扑。
    2. 在左侧设备栏选择 路由器 (Router)，拖入两台 AR2220 路由器。
    3. 选择 终端 (End Device)，拖入两台 PC 终端机。
    4. 使用 连接线 (Copper)，将 PC1 连接至路由器 R1 的 GigabitEthernet 0/0/0，PC2 连接至路由器 R2 的 GigabitEthernet 0/0/0；R1 的 GigabitEthernet 0/0/1 与 R2 的 GigabitEthernet 0/0/1 互连。
    5. 点击工具栏的"开启"按钮，等待设备图标由红变绿。

四、思考题

  1. 路由方式对比：静态路由、RIP 和 OSPF 三种路由方式各有什么优缺点？分别适用于什么场景？
  2. RIP 与 OSPF 的区别：RIP 使用 network 宣告时用的是主类网络地址（如 12.0.0.0），而 OSPF 使用的是反掩码（如 12.1.1.0 0.0.0.255），二者为什么不同？
  3. OSPF 区域：本实验中 OSPF 只使用了 Area 0（骨干区域），如果网络规模扩大，引入多区域划分有什么好处？
